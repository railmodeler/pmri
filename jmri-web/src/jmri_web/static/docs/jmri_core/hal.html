Hardware Abstraction Layer — connection ABC and in-memory loopback.

Concrete drivers (LocoNet, NCE, DCC-EX, etc.) live in their own packages and subclass jmri_core.hal.connection.SystemConnection. They register themselves via the jmri.connection entry point so load_connections() in jmri_core.plugins can discover them.

 66        self.consists: ConsistManager       = self._make_consist_manager()
 67        # The four beans added in the "missing JSON topics" pass. These
 68        # are software-only for every driver — no wire ops attached to

 70        # occupancy logic on layout blocks or oblocks. Managers are

 74        self.audios: AudioManager           = self._make_audio_manager()

 80        # Command-station reachability. Optimistic default: drivers
 81        # that don't implement heartbeat detection stay at True while
 82        # the connection is open, so the base behaviour matches
 83        # ``is_open``. Drivers with real detection call
 84        # :meth:`_set_cs_reachable` from their traffic controller to
 85        # flip this in response to actual bus activity.

111    @property
112    def is_command_station_on(self) -> bool:
113        """True when the command station itself has power.
114
115        Distinct from :attr:`PowerManager.state` (which is the DCC
116        *track* power — the CS driving DCC on the rails or not).
117
118        Value is ``is_open AND _cs_reachable`` — so a closed
119        connection is always Off, and a driver with real detection
120        (NCE, LocoNet, DCC-EX) can drop the reachable flag when it
121        loses contact with the CS without touching ``is_open``.
122        Drivers that don't implement detection leave ``_cs_reachable``
123        at its optimistic True default, so their behaviour matches
124        ``is_open`` exactly — no regression.
125        """
126        return self._opened and self._cs_reachable
127
128    async def _set_cs_reachable(self, reachable: bool) -> None:
129        """Driver hook — call from your traffic controller when you
130        detect a CS-on ↔ CS-off transition.
131
132        Debounces: no-op when the state hasn't changed. Emits
133        :attr:`command_station_power_changed` with the new
134        :attr:`is_command_station_on` value (which folds in the
135        ``is_open`` gate) so subscribers always see the effective
136        power state.
137        """
138        if self._cs_reachable == reachable:
139            return
140        self._cs_reachable = reachable
141        await self.command_station_power_changed.emit(self.is_command_station_on)
