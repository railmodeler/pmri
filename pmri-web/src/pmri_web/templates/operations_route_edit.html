Route

Direction

The pair of cardinal directions the route spans, and which of them is the superior direction. Stop order below should run in the superior direction (so the first stop is the origin for a superior-direction train). Not enforced; the By Route timetable relies on this convention.

Branch

A route is a mainline unless marked as a branch. A branch attaches to a mainline at one of that mainline's stops and inherits its direction + superior direction automatically.

Stops

Order the stations in the superior direction (easternmost first for a westward superior route, northernmost first for a southward superior route, etc.). Miles is the distance to this stop from the previous one; first stop is 0. Stop type is a railroad-local letter code (s, f, c, ...). Facilities and siding capacity live on the Station itself.
