{# Depart-time picker macro -- renders a 24h-canonical input pair plus an overlay 12h face (hour + minute + AM/PM) and a "12-hour" toggle that flips between them. Both pages that collect a departure time (train create on /operations/trains and train edit) include this so the behaviour and keyboard focus order stay identical. The widget persists the selected format under ``localStorage.fcFormat12`` -- the same key the Fast Clock on the home tab reads/writes -- so a user who prefers 12h sees that face everywhere without re-selecting. Scoping: every instance carries a unique ``widget_id`` so the inline JS can find its own wrapper by ``data-depart-widget=""`` rather than grabbing the page's first form (which in base.html is the logout form in the header). Pass ``widget_id`` so two instances on one page can coexist. Args: widget_id -- stable DOM id for this instance (e.g. "create", "edit"). hour -- stored 24h hour (0..23) as a string, "" if unset. minute -- stored minute (0..59) as a string, "" if unset. required -- if truthy, mark the 24h inputs as HTML required. #} {% macro depart_time_widget(widget_id, hour, minute, required=False) %}
{% endmacro %} {# Companion script -- emit ONCE per page that uses the macro. Locates every ``.depart-time-widget`` wrapper, wires both faces together, and initialises the toggle from ``localStorage.fcFormat12``. #} {% macro depart_time_script() %} {% endmacro %}
