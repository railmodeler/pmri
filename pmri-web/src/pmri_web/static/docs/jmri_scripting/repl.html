jmri_scripting.repl

Interactive Python REPL bound to the JMRI shim.

The batch script runner in jmri_scripting.runner compiles and runs a whole file per submission with a fresh globals namespace each time. That's the right shape for automatons and one-shot utilities, but it's a lousy fit for the "let me poke at the layout interactively" workflow every layout builder actually wants — you lose every variable and import as soon as the script ends.

This module provides the interactive companion. One persistent code.InteractiveInterpreter per server, pre-seeded with the shim's globals (sensors, turnouts, ACTIVE, everything). Submit a fragment via ReplSession.submit() and get back a ReplResult carrying the captured stdout, stderr, and the last expression's repr — the Jupyter-cell shape.

State persists across submissions until ReplSession.reset() is called, which rebuilds the interpreter (and drops every user variable, import, and function).

Multi-line handling — a submission that ends with an unfinished statement (an open def, a hanging if, an unclosed bracket) needs to accumulate until the next submission. _needs_continuation() uses code.compile_command() to detect that case; the caller sees result.incomplete == True and knows to append the next fragment before re-submitting.

Concurrency — a single lock serialises submissions so two browser tabs can't race and corrupt the interpreter state. The lock is contested only during submit, which does CPU-bound work with the GIL held anyway; overhead is negligible.

 94_MAX_HISTORY_ENTRIES = 100
 95_MAX_STDOUT_PER_ENTRY = 64 * 1024

 98def _needs_continuation(source: str) -> bool:
 99    """Return True when *source* is syntactically incomplete —
100    i.e. the user needs to keep typing before we can compile.
101
102    :func:`code.compile_command` returns ``None`` for that case,
103    a code object when compilable, and raises for a hard syntax
104    error. We treat the hard error as "compilable enough to try
105    executing", letting the ``exec`` path surface the traceback
106    — matches how Python's own REPL behaves."""
107    try:
108        result = code.compile_command(source, "<repl>", "single")
109    except (SyntaxError, OverflowError, ValueError):
110        return False
111    return result is None

114class ReplSession:
115    """Persistent Python interpreter bound to the JMRI shim.
116
117    One instance per server. Callers submit source fragments via
118    :meth:`submit`; state persists across submissions until
119    :meth:`reset` is called.
120    """
121
122    def __init__(self, shim: JmriShim) -> None:
123        self._shim = shim
124        self._lock = threading.Lock()
125        self._history: list[ReplEntry] = []
126        self._globals: dict[str, Any] = {}
127        # Build the initial namespace so the very first submission
128        # already has ``sensors`` / ``turnouts`` / etc. available.
129        self._install_globals()
130
131    def _install_globals(self) -> None:
132        """Populate ``self._globals`` with the shim's injected names
133        plus a couple of REPL-friendly built-ins."""
134        self._globals = {
135            "__name__": "__jmri_repl__",
136            "__builtins__": __builtins__,
137            **self._shim.globals(),
138        }
139        # A friendly reference to the shim itself, for scripts that
140        # want to reach through to the underlying async connection.
141        self._globals["shim"] = self._shim
142
143    # ---- public API ----------------------------------------------------
144
145    @property
146    def history(self) -> list[ReplEntry]:
147        """Snapshot of the history buffer, oldest first."""
148        with self._lock:
149            return list(self._history)
150
151    def reset(self) -> None:
152        """Rebuild the interpreter — drops every user variable,
153        import, and function definition. History is cleared too."""
154        with self._lock:
155            self._history.clear()
156            self._install_globals()
157
158    def submit(self, source: str) -> ReplResult:
159        """Execute *source* against the persistent interpreter.
160
161        Returns a :class:`ReplResult`. Bounded stdout capture means
162        a script that prints megabytes only surfaces the first
163        64 KB — a runaway loop can't OOM the server.
164
165        **Threading note**: this method blocks synchronously on the
166        current thread. It must NOT be called from the event-loop
167        thread if the submitted source might touch the shim, because
168        the shim's ``_block(loop, coro)`` schedules coroutines onto
169        that loop and waits for them — the loop can't advance if the
170        caller is holding its thread. Two supported patterns:
171
172        * **From an async coroutine on the loop thread**: wrap in
173          ``asyncio.to_thread(repl.submit, source)`` — that off-loads
174          the exec to a worker so the loop stays free.
175        * **From any other thread** (batch worker, sync test): call
176          directly.
177
178        :meth:`submit_async` is a thin async wrapper that does the
179        ``to_thread`` for you; web routes use it.
180        """
181        with self._lock:
182            # Incomplete? Client keeps accumulating.
183            if _needs_continuation(source):
184                entry = ReplEntry(source=source)
185                return ReplResult(entry=entry, incomplete=True)
186
187            entry = ReplEntry(source=source)
188            self._exec_one(source, entry)
189            self._push_entry(entry)
190            return ReplResult(entry=entry, incomplete=False)
191
192    async def submit_async(self, source: str) -> ReplResult:
193        """Async wrapper — safe to call from a coroutine running on
194        the same event loop the shim binds to. Off-loads the sync
195        exec to a worker thread so the loop stays free to service
196        shim coroutines."""
197        import asyncio  # noqa: PLC0415
198        return await asyncio.to_thread(self.submit, source)
199
200    # ---- internals ----------------------------------------------------
201
202    def _exec_one(self, source: str, entry: ReplEntry) -> None:
203        """Run *source* under stdout/stderr capture, filling *entry*.
204
205        Binds the shim to the current thread so
206        ``jmri.InstanceManager.getDefault(...)`` resolves — the shim
207        is thread-local (matches the batch runner's convention where
208        each script's worker thread gets its own bind).
209        """
210        from jmri_scripting import jython_shim  # noqa: PLC0415
211
212        stdout_buf = io.StringIO()
213        stderr_buf = io.StringIO()
214
215        jython_shim._bind_shim(self._shim)
216        try:
217            with (
218                contextlib.redirect_stdout(stdout_buf),
219                contextlib.redirect_stderr(stderr_buf),
220            ):
221                self._run_source_capturing(source)
222        except SystemExit:
223            entry.error = "SystemExit: refused to exit the server"
224        except BaseException:  # noqa: BLE001
225            entry.error = traceback.format_exc()
226        finally:
227            jython_shim._unbind_shim()
228
229        entry.stdout = _clip(stdout_buf.getvalue(), _MAX_STDOUT_PER_ENTRY)
230        entry.stderr = _clip(stderr_buf.getvalue(), _MAX_STDOUT_PER_ENTRY)
231
232    def _run_source_capturing(self, source: str) -> None:
233        """Two-pass compile: try as an expression to surface the
234        result via ``repr()``, else exec as statements.
235
236        Mirrors CPython's REPL: a bare expression at the prompt
237        prints its ``repr``; a statement produces no automatic
238        output. Storing the result on the *entry* is done by the
239        caller via ``__last_result__``.
240        """
241        # ``self._entry_being_run`` set by ``_exec_one`` so the
242        # ``compile...eval`` branch can stash the result. Threaded
243        # through a per-call attribute rather than a return value so
244        # the exception paths above can still see the partial
245        # entry state.
246        try:
247            expr_code = compile(source, "<repl>", "eval")
248        except SyntaxError:
249            expr_code = None
250
251        if expr_code is not None:
252            result = eval(expr_code, self._globals)  # noqa: S307
253            if result is not None:
254                # Print ``repr`` to stdout so the console rendering
255                # is one uniform place — no separate "result" cell.
256                print(repr(result))
257            return
258
259        # Statement form: compile + exec.
260        stmt_code = compile(source, "<repl>", "exec")
261        exec(stmt_code, self._globals)  # noqa: S102
262
263    def _push_entry(self, entry: ReplEntry) -> None:
264        self._history.append(entry)
265        overflow = len(self._history) - _MAX_HISTORY_ENTRIES
266        if overflow > 0:
267            del self._history[:overflow]
268

270def _clip(text: str, limit: int) -> str:
271    """Truncate *text* to *limit* bytes with a leading marker.
272
273    Called for both stdout and stderr per entry. Keeping the
274    trailing bytes (the freshest output) matches what an operator
275    watching a runaway loop expects — the "last thing before it
276    went wrong" is what they need to see."""
277    if len(text) <= limit:
278        return text
279    dropped = len(text) - limit
280    marker = f"... ({dropped} bytes elided) ...\n"
281    return marker + text[dropped + len(marker):]
